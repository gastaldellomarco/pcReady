## Technology stack

pcReady is built on a modern TypeScript stack:

- **Frontend**: React 19 + TanStack Router/Start (file-based routing)
- **Styling**: Tailwind CSS 4 + shadcn/ui components
- **Backend**: Supabase (Postgres, Auth, RLS, Realtime, Storage)
- **Build**: Vite 7 + Bun
- **Deploy**: Vite + Bun
- **Testing**: Vitest (unit), Playwright (E2E)
